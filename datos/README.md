# datos/

Aquí sube Juan cada semana la **hoja masiva descargada** de Amazon Ads (Operaciones en bloque → Crear hoja de cálculo para descargar → Sponsored Products, rango desde la creación de las campañas hasta hoy, con campañas en pausa).

Opcional: informe de **términos de búsqueda** de las últimas 2 semanas.

La tarea semanal (skill `revision-semanal`) lo lee cada lunes y devuelve en `resultados/` el informe, la memoria actualizada y el bulk de cambios.
